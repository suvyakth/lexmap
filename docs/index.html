Rent caps, just-cause eviction, deposits, fees, tenant screening and algorithmic rent-setting. Every answer quotes the law it comes from, and says "unknown" instead of guessing.

    How an answer is made

    1. Read. An AI model reads 67 state and city law documents and turns each rule into machine-checkable conditions.
    2. Verify. Every quote is located in the source file, and a second review pass checks each cut-off date and exemption.
    3. Locate. The U.S. Census Geocoder finds the address's legal city; public parcel records add building facts where available.
    4. Decide. A deterministic engine applies the rules: applies, unknown, superseded, not yet effective or pending.

    How Lexmap works

    Rules compile to executable coverage logic, so each answer is an evaluation you can audit, not a generated guess.
